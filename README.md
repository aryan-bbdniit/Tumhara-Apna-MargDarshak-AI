# Tumhara-Apna-MargDarshak-AI 🤖🎓

My first B.Tech project - a personalized, AI-driven career guidance chatbot built entirely using Python on mobile!

## ⚠️ Work In Progress (WIP)
This project is currently under active development. New logic and cybersecurity features are being added step-by-step.

## 🚀 Features (Version 1.0)
- Interactive Main Menu with user name tracking
- 12th Marks scanner for college placements insight
- Multidisciplinary Career Fields Guidance (Web Dev, AI/ML, Android, Cyber Security, Data Science)
- Built-in input verification & error handling

## 🛠️ Tech Stack
- **Language:** Python 3
- **Platform:** Pydroid 3 (Mobile Development)
